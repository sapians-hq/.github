## What lives here

This is the canonical GitHub namespace for **SAPIANS Estúdio de Soluções em Negócios Ltda.**
Work is organized in tiers, each with its own support and CI contract:

| Tier | Meaning |
| :--- | :--- |
| **A** | Production systems — supported, released, versioned |
| **B** | Client engagements — private, contract-scoped |
| **I** | Internal tooling and shared infrastructure |
| **C** | Research and teaching artifacts — papers, lectures, datasets |
| **D** | Drafts and experiments — no stability guarantees |

Every repository declares its tier in `.sapians-repo.yml`.

## Conventions

- **Default branch:** `main`
- **Releases:** semantic versioning, automated via Release Please
- **Shared CI:** reusable workflows live in this repository
- **Security:** secret scanning with push protection, Dependabot alerts, and
  dependency graph are enabled by default on every new repository
