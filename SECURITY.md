# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report vulnerabilities privately to **[hello@sapians.com.br](mailto:hello@sapians.com.br)**,
or through GitHub's [private vulnerability reporting](https://docs.github.com/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability)
on the affected repository.

Include, where possible: affected repository and version, reproduction steps,
and the impact you observed. We aim to acknowledge reports within five business days.

## Scope

This policy covers repositories owned by the `sapians-hq` organization.
Client engagements under NDA may have their own reporting channel defined in
the respective contract — when in doubt, use the address above.

## Supported versions

Only the latest released version of each project receives security fixes,
unless a repository states otherwise in its own `SECURITY.md`.
